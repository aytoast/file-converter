# Windows 右键入口接入

状态：接口方案，尚未注册菜单或提供原生安装程序。

## 参数

原生入口从资源管理器取得所选文件路径和目标格式，向独立工作进程传入结构化任务。概念任务如下，具体协议按天禧 SDK 确定：

```json
{
  "inputs": ["C:\\Users\\User\\Pictures\\photo.png"],
  "format": "jpg",
  "output_dir": null,
  "background": null
}
```

输出目录为空表示原目录。透明度处理等决策未完成时打开必要选项，不能静默选择背景。

CLI 的 --input 可重复传入。菜单可调用 --targets --input <文件> 获取依赖感知的候选目标。原生进程用参数数组调用 Python，禁止通过拼接 cmd.exe 或 PowerShell 命令传入文件名。大批量文件应通过任务清单或进程间通信传递，当前 CLI 原型受系统命令行长度限制。

## 拟议菜单

图片、媒体、Office、PDF、表格等菜单目标根据脚本返回动态生成。多结果任务须使用完整 outputs 列表；只读取 output 会遗漏其他页面或工作表。

新增识别与专业路线后，菜单标签需明确任务语义：PDF → PDF 显示“可搜索 PDF”并传 --ocr；images 显示“提取嵌入图片”，frames 显示“提取图片序列”。图片转 SVG 显示“单色矢量描摹”，识别为 ASR 的音视频文字目标需本地模型路径。--targets 返回候选格式，不等于全部任务参数已经齐备。

3D 几何输出、图片型 PPTX、GPX 属性减少等损失选择须由清楚的任务语义或用户选项表达，不能静默追加 --allow-layout-loss 来绕过检查。GIS 缺少 CRS、数据有多个图层、字体集合缺少索引时，应展示对应必要选项。

菜单按源文件类型、工具可用性和实际目标筛选。菜单展开时不执行全文解码或模型调用；工作进程在用户选择后执行。初版可在选择后再检查精细内容边界，例如动画和额外轨道。

保留键盘导航与原生菜单行为。进度和结果集中展示，完成提供打开文件、打开目录；失败项可单独重试。界面实现需先进入独立 Current/New 评审，用户确认后再集成。

## 平台条件

Windows 11 主菜单接入需按目标系统验证 IExplorerCommand、应用身份与扩展注册。传统注册表命令可能位于“显示更多选项”，不能当作主菜单已接入。安装与卸载成对管理注册。

天禧技能市场需确认：允许的包内容、本地脚本/可执行文件权限、依赖与编码器分发、右键注册、安装授权、任务反馈接口。仅有 SKILL.md 不会自动注册系统菜单。

若平台不支持原生扩展，先保留对话入口，或经明确授权安装伴随应用。不能宣称下载本包即可获得右键菜单。

## 原型限制与验收

当前工作进程提供转换和逐项 JSON 结果，不提供原生进度窗口、桌面通知或每任务 GUI 取消。集成后验证 Explorer 响应、多选、中文路径、重名、依赖缺失、部分失败、取消、安装与卸载。
